# Until 25
This is the signature type-face designed for my brand, designed for use in all forms of graphics related to my work as [SweetBoy](https://SweetBoy13735.GitHub.IO). As such, support is limited to italic, Basic Latin alpha-numerics in addition to the hyphen and underscore.

## Support
If you encounter any issues with the font, please feel free to [create an issue](https://GitHub.com/SweetBoy13735/Until-25/issues) (Provided it hasn't been logged already).

## Roadmap
As of V1's release, this project is considered **complete**. Whilst further development is largely limited to hot-fixes, additional glyphs may be added in future minor releases.
