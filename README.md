# Until 25
[![Contributor Covenant](https://img.shields.io/badge/Contributor_Covenant-v3.0_adopted-900.svg)](https://GitHub.com/SweetBoy13735/Until-25/blob/Main/CODE_OF_CONDUCT.md)

This is the signature type-face designed for my brand, designed for use in all forms of graphics related to my work as [SweetBoy](https://SweetBoy13735.GitHub.IO). As such, support is limited to italic, Basic Latin alpha-numerics in addition to the hyphen and underscore.

## Installation
To install the font, simply select a release and download either the `.otf` or `.svg` files listed.

## Support
If you encounter any odd behaviour, please feel free to [create an issue](https://GitHub.com/SweetBoy13735/Until-25/issues) or [E-Mail me](mailto:Ramone@SweetBoy13735.Me.UK).

## Roadmap
As of V1's release, this project is considered **complete**. Whilst further development is largely limited to hot-fixes, additional glyphs may be added in future minor releases.
